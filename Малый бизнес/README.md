# Малый бизнес с нуля

Курс на 16 недель: от первой идеи до бизнес-плана, налогов, бухучёта, права и господдержки. Цифры и законы — на 2026 год.

| Файл | Что внутри |
| --- | --- |
| `Уровень 1 — основы` (.md / .pdf) | Модули 1–8: идея и юнит-экономика, юрформы, налоги, деньги и учёт, документы, сотрудники, продажи, риски. Шпаргалка, что выучить, словарь на 117 терминов, налоговый календарь |
| `Уровень 2 — углублённый` (.md / .pdf) | Модули 9–16: финансы, бухгалтерия, налоги углублённо, право, трудовое право, маркетплейсы, управление, господдержка. Задачник на 20 задач с ответами и итоговый экзамен |

PDF — для чтения с телефона, Markdown — для правок и поиска.
